## 已实现的行为

- 字幕栏「保存 Markdown」打开独立窗口，固定当前视频信息和字幕，切换视频不改变待保存内容。
- 保存前可修改属性、预览 Markdown、选择目录或复用默认目录。文件名使用标题加 `.md`，非法字符替换后显示实际文件名。
- 字幕以实际提取的语言为准，不使用侧栏翻译、不附加时间戳。保存原文中的姓名；旧缓存缺少原始切换标记时提示限制。
- 模板支持新建、复制、删除、属性增删排序、正文编辑、JSON 导入和导出。不支持的变量／规则要求修正；路径、文件名、匹配与追加等行为差异要求确认转换说明。
- 姓名识别复用当前 DeepSeek 或 Codex 配置。模型仅返回候选、发言范围和原文依据，用户确认后才写入；可修改、移除或手动添加标注。
- 同名文件询问覆盖，取消不打开写入流。写入流成功关闭后才报告已保存。
- 刷新同一保存窗口可恢复文档属性、模板选择和已确认标注。默认目录通过目录句柄保存，权限仍由浏览器管理。
